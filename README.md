# Project Title

This project builds a machine learning model to solve a real-world problem using PySpark and MLflow.

## Problem Statement
This project is to analyze the data and predict / analyze customer behavior

## Tech Stack
- Python, PySpark
- MLflow
- Azure / local setup
- scikit-learn, pandas, matplotlib

## Folder Structure
- `notebooks/`: EDA, feature engineering, modeling
- `src/`: Scripts for data processing, model training, inference
- `data/`: Raw and processed data
- `outputs/`: Charts and reports
- `mlflow_logs/`: MLflow tracking data

## To Run
```bash
pip install -r requirements.txt
python src/train_model.py
```
